# MadlibsGame
# Python Mad Libs

A simple Python project built while learning Python fundamentals.

This program asks the user for a few words and creates a funny story using those inputs.

## Features

- User input with `input()`
- Variables
- Formatted output using f-strings
- Simple terminal-based interaction

## Concepts Practiced

- Python syntax
- Variables
- Strings
- User input
- `print()`
- f-strings

## Sample Output

```text
Pick an adjective: funny
Pick a noun: elephant
Pick a verb: dancing

I went to the zoo today!
I saw a zebra which is funny.
As I was seeing it, it suddenly started dancing.
It ran towards an elephant and everyone started laughing!
```
